## Overview

This project explores a novel attack vector against fake news detection systems by leveraging Explainable AI (XAI) techniques to guide Large Language Models (LLMs) in generating adversarial comments. The approach identifies vulnerabilities in existing fake news detectors and demonstrates how XAI explanations can be exploited to craft more effective adversarial examples.

## Key Features

- XAI-guided adversarial comment generation
- Integration with multiple LLMs for attack generation
- Comprehensive evaluation against state-of-the-art fake news detectors
- Attack success metrics and analysis tools

## Installation

1. Clone the repository:
```bash
git clone https://github.com/shoaibmehrab/xsi-llms-attack.git
cd xsi-llms-attack
```

2. Create a virtual environment:
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

3. Install dependencies:
```bash
pip install -r requirements.txt
```
